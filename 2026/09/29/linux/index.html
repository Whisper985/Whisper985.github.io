3. 编辑与查看文件

vi 编辑器类似记事本，例如 vi test02.txt。vi 的三种模式：

  • 常规模式：默认模式，可使用各种快捷键快速编辑文件，如 dd 删除当前行。
  • 编辑模式：在常规模式下按 i / o / a 任一键进入，写完内容后按 Esc 回到常规模式。
  • 命令模式：在常规模式下按英文冒号 : 进入。常用命令：q 退出、wq 保存并退出、q! 强制退出不保存、set number 显示行号。

4. 修改目录（文件夹）的所属

  • 文件权限 rwx 表示读、写、执行。
  • 目录权限：r 表示可以查看目录下有哪些文件；x 表示可以 cd 切换到该目录；w 表示可以在目录中创建、修改、删除文件。

安全建议：

  • 文件权限默认 644，更严格可用 600。
  • 目录权限默认 755，更严格可用 700。

5. 文件属性详解

属性字段说明：

  • 第 1 个字符表示文件类型：- 文件、d 目录、l 软链接（类似 Windows 快捷方式）、b 块设备（ls /dev 可看到 sda 等硬盘）。
  • 第 2~4 个字符：文件所属用户的权限。
  • 第 5~7 个字符：文件所属用户组的权限。
  • 第 8~10 个字符：其他用户的权限。
  • 示例中的 0 是文件大小，单位为 B。

Linux 系统记录三个时间：访问时间、修改时间（文件内容改变）、改变时间（文件属性改变）。
